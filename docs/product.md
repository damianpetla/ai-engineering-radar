# Product

Authority: specification 1.1 in `spec-v1.1.txt`.

A single public dashboard of observed AI engineering activity. A compact header leads to a multi-series weekly chart and a searchable, sortable topic list. Each row expands into its chart, counts, and primary evidence. Stable topic slugs live in the `topic` query parameter; browser history restores selection.

The dashboard offers 30, 90, and 180 day windows, up to four chart series, publication excerpts, publication/observation dates, source groups, coverage information, and unobtrusive methodology dialogs. Unknown topic slugs leave the dashboard usable. Empty ranges, empty search, validation failures, loading, and overdue collection have explicit states.

Activity describes the monitored publishing sample. It never establishes adoption, quality, or effectiveness. The UI contains no adoption stages or recommendations.
